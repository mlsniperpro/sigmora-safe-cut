# SAFECUT-SAFETY: owner inputs (nothing here blocks the code; each path already runs on replay or a fallback)

- [ ] **EgoBlur Gen 2 weights (owner step O8).** Open <https://www.projectaria.com/tools/egoblur/>, submit the request form with your own name and email, download `ego_blur_face_gen2.zip` and `ego_blur_lp_gen2.zip` (and the Gen 1 pair for the comparison), unzip to `ego_blur_face_gen2.jit` / `ego_blur_lp_gen2.jit`, and put them in the private bucket under `models/egoblur/gen2/` (never in this repo). Set `SAFECUT_EGOBLUR_WEIGHTS_DIR` to the folder that holds them (or its parent; `gen2/` is searched). Until then the audit runs the bundled YuNet face detector and records `yunet-face` (plates: red team only) in `audit.json` and the receipt. Proof it works the moment they land: `uv run python -c "from safecut.config import load_settings; from safecut.audit.detectors import load_detector; print(load_detector(load_settings()).model)"` prints `egoblur-gen2`.
- [ ] **`MODEL_API_KEY` in the cloud environment, with `api.meta.ai` allowed.** Needed for the live Muse Spark red team (`LiveRedTeam`). Then run `uv run pytest -m live -k redteam` (one red-team call on a synthetic frame, about $0.01) and `scripts/go-live.sh <clip>`, which records the red team's answers to `raw/redteam/frames.json` for replay. Without it, replay serves recorded answers and synthetic jobs use the labelled ground-truth oracle.
- [ ] **A consented hero clip (`docs/SHOTLIST.md`) with its labels**, for WP4's "unresolved == 0 on hero clip 1 (live)" and the reversibility check on real faces. Today the check runs on drawn synthetic faces: YuNet finds the bystander in the source on ≥ 80 % of frames and on 0 rendered frames (`tests/test_render.py::test_reversibility_a_face_detector_finds_no_pixelated_face`).
- [ ] **A GPU for EgoBlur in production (Modal tokens, SHIP's deploy).** EgoBlur on CPU is about 1.5 s per frame per model, roughly 45 minutes for a 30 s clip, so the service runs it on a Modal GPU through `safecut/audit/gpu.py` (`detect_png` in the function, `RemoteDetector` in the audit). YuNet needs no GPU (≈ 2–3 ms a frame measured, `raw/audit/run.json`).
