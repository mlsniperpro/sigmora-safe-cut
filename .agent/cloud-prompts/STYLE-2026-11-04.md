## Why (owner, 11-04, after watching the live review of the street-interview clip)

The owner said hidden people are covered with a "blanket" that is too disruptive. Production videos only cover
enough to hide identity. What the live review shows on `street-interview.mp4` (job `j_bOnehM8xFcyRxZXQ0X6gmg`):
one held participant (Face 1, the interviewer in "Needs you") becomes a dark slate rectangle over the right half
of the frame. Bystanders get whole-body slate silhouettes. The result looks broken, not edited.

Cause: `safecut/decide/policy.py:style_for`. A prominent person (`PROMINENT_HEIGHT = 0.25`), a face close-up or a
child gets `person_solid`, a whole-body opaque fill plus `guard/plan.py:_with_body`. Every `pixelate` item still
draws its body (`person`) tracks too, because `plan()` iterates all `item.track_ids`.

## Decision (made; don't re-litigate)

The default redaction is **identity-only**: cover the face/head, not the body.

1. **People and children** (hidden, held for review, or "Needs you"): use the existing coarse **locked-grid mosaic**
   (`pixelate`: ≤6 cells across the face, fixed per-cell noise, grid locked to the track) over the **face region
   only**, with the face padding (`PADDING.face`).
   - Do not draw an item's `person` (body) tracks on frames where one of the item's face tracks has a region.
   - On frames where the item has a body region but no face region (face missed, turned away, between face
     detections), cover a **head estimate**: the top of the body box, full box width × height
     `min(0.22·h, 0.9·w)`, padded like a face. Use the mosaic with the item's grid, or `solid` if the item has no
     face track to size a grid. Never draw the whole body.
   - Children stay **locked hidden** (no Keep clear, closure via `child_links` unchanged); only the style changes.
   - The face mosaic must stay unreadable. Keep the §2.7 rules (coarse cells, noise, locked grid). Never use blur.
2. `person_solid` (the whole person) is used **only** for the creator's explicit **Remove person** action. The
   contract at `contracts.py:527` already ties it to that action. `style_for` and `review._default_style` never
   return it otherwise. Delete `PROMINENT_HEIGHT`/close-up logic, or keep it only if something else needs it.
3. **Objects** (plates, screens, documents, text): unchanged (`solid` on the object's own mask/box; mosaics are
   reversible for text). Crowd fills: unchanged.
4. **Web preview** (`web/src/lib/overlay.ts`, `VideoPane.tsx`): it must draw exactly what the render draws. Mosaic
   over the face region for pixelate covers, using the mask runs when present; a rectangle only for `solid` box
   entries and crowd fills. No big dark rectangles for people.
5. Safety nets stay: the audit (YuNet face detector + Muse Spark red-team) runs on every rendered frame and patches
   any leak. Add a test that a face mosaic at the real cell size is NOT detected as a face by the audit detector
   path used live (`SAFECUT_AUDIT_GPU=0`, YuNet). If YuNet does detect it, make the cells coarser (fewer per face),
   never finer.
